# Quiz App

A full-stack Quiz Application built using Spring Boot and React that allows users to attempt quizzes, view scores, and manage questions efficiently.

---

##  Features

-  Create and manage quiz questions
-  Attempt quizzes with multiple-choice questions
-  View scores instantly after submission
-  RESTful APIs for seamless communication
-  Clean and responsive UI
-  Fast performance with optimized backend

---

## Tech Stack

**Frontend:**
- React.js
- Axios
- HTML, CSS

**Backend:**
- Spring Boot
- Java
- REST APIs

**Database:**
- MySQl
